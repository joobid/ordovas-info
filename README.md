# Historia de la familia Ordovás

Web estática (HTML, CSS y JS) con las memorias de familia de José Luis Ordovás Blasco.

- `index.html`: la página completa
- `css/style.css`, `js/main.js`: estilos y comportamiento
- `img/`: fotografías y documentos
- `descargar-imagenes.sh`: descarga las imágenes originales de ordovas.info
- `CORRECCIONES.md`: erratas corregidas y dudas pendientes
